# Hypathon App

This app uses the Neynar Mini App Template to create a webpage and mini app for Base and Farcaster.

It allows you to query a indexing.co Farcaster Database to see how many times a certain string (we use it for domains) was shared.

>**NOTE** Deployment on Vercel won't work!!! Since the database query without indexes will run for ~10 minutes. Vercel functions time out after 1 minute by default. Take note of that.

Enjoy!

For more Farcaster docs and apps see [the dTech webpage](https://dtech.vision)
