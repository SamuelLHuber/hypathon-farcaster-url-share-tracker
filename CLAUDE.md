# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Development Commands

**Development:**
- `npm run dev` - Start development server with tunnel support (set USE_TUNNEL=true in .env.local for external access)
- `npm run cleanup` - Kill processes on port 3000 (useful when dev server gets stuck)

**Build & Deploy:**
- `npm run build` - Production build (also runs the build script that generates .env with manifest)
- `npm run start` - Start production server
- `npm run deploy:vercel` - Deploy to Vercel

**Code Quality:**
- `npm run lint` - Run ESLint

**Database (Drizzle):**
- `npm run db:generate` - Generate new migrations from schema changes
- `npm run db:migrate` - Apply pending migrations to database
- `npm run db:push` - Push schema changes directly to database
- `npm run db:studio` - Open Drizzle Studio for database management

## Architecture Overview

**Framework:** Next.js 15 with App Router, TypeScript, and Tailwind CSS

**Authentication:** Farcaster QuickAuth integration with JWT verification
- All protected API routes must use `verifyAuth()` from `~/lib/auth`
- Client-side authenticated requests must use `fetchWithAuth()` instead of fetch
- Authentication state managed through Farcaster SDK

**Database:** PostgreSQL with Drizzle ORM
- Schema: `src/db/schema.ts` - Farcaster-focused tables (casts, profiles, reactions, links, verifications)
- Relations: `src/db/relations.ts` - Table relationships for joins
- Connection: `src/db/index.ts` - Database client exported as `db`
- Config: `drizzle.config.ts` - Uses DATABASE_URL environment variable

**Key Providers:**
- `MiniAppProvider` from @neynar/react - Wraps app for Farcaster mini app context
- `WagmiProvider` - Ethereum wallet integration (dynamically loaded)
- Both providers configured in `src/app/providers.tsx`

**Development Setup:**
- Custom dev script (`scripts/dev.js`) handles port management and optional tunneling
- Build script (`scripts/build.js`) generates Farcaster manifest and environment setup
- Environment variables loaded from .env (production) and .env.local (development)

**API Architecture:**
- Protected routes in `src/app/api/` directories
- Authentication verification pattern: Extract Bearer token → verify with QuickAuth → return FID
- Webhook endpoint for Farcaster events at `/api/webhook`

**Frontend Patterns:**
- Semantic Tailwind classes preferred (bg-card, text-foreground) over hardcoded colors
- UI components in `src/components/ui/`
- Theme variables defined in `globals.css`

**Important Files:**
- `src/lib/auth.ts` - Authentication utilities and user info fetching
- `src/lib/constants.ts` - App constants
- `src/lib/neynar.ts` - Neynar API integration
- `.cursor/rules/ai-context.mdc` - Additional development guidelines

**Environment Variables Required:**
- `DATABASE_URL` - PostgreSQL connection string
- `NEXT_PUBLIC_URL` - App URL for authentication domain
- `NEYNAR_API_KEY` - Optional Neynar API access
- Farcaster manifest variables (auto-generated by build script)
